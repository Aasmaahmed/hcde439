Assignment 1!

For assignment 1, I used 6 LED lights, 2 of the same color to create a pattern of lights blink! The pattern starts with lighting all LEDS then the LEDS of the same color, then each one idiviually.

Schematic:

Schematic of each LED, I used 100 ohms resistor for each circut based on the calculation showed. 100 ohms is the closest value available.

        // Added the LEDS as global variables

        void setup() {

2: There are 12 pins in the Arduino board, so 12 LEDS can blink independently. Each LED current is 20 mA, the total current is: 12 x 20mA = 240mA. This exceeds the recommended total current limit for Arduino pins. Therefore, reducing the current to 10mA per LED, gives us a total current of 120mA which is within the recommended current limit.

3: The LEDs need a delay of approximately 10 ms or less between turning on and off, which equals 50 flashes per second. At this speed, the blinking becomes difficult to notice, and the LEDs appear continuously lit.
