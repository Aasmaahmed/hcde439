Assignment 4!

For this assignment, I built a smart door that opens automatically when an ultrasonic sensor detects someone approaching within 15 cm. I also added a capacitive touch sensor to allow the door to open manually. A servo motor controls the door's movement, while green and red LEDs indicate whether the door is open or closed.

Ardunio code snippet:

       // adding libraries for ultrasonic new ping, servo motor, and capacitive sensor
        #include NewPing.h

        #include Servo.h

        #include CapacitiveSensor.h

        // create Servo object to control a servo
        Servo myservo;  
        // set pin 13 as the sender pin and pin 12 as the sensor or receiver pin
        CapacitiveSensor   touchSensor = CapacitiveSensor(13,12);        
        // ultrasound pin constants
        const int trigPin = 7;
        const int echoPin = 8;
        // Led constants
        const int greenLed = 2;
        const int redLed = 4;
        // maximum ultrasonic sensing distance we want to ping for (in centimeters).
        const int maxDistance = 200;
        // initialize the ultrasonic sensor using the Newping library
        NewPing sonar(trigPin, echoPin, maxDistance);
        // setting threshold value for capacitive sensor, so the door opens when it reaches it
        int threshold = 500;

        void setup() {
            // initialize serial communication
            Serial.begin(9600);
            // Setting output and input modes for led
            pinMode(greenLed, OUTPUT);
            pinMode(redLed, OUTPUT);
            // attaches the servo on pin 10 to the Servo object
            myservo.attach(10);  
            // intialize the door to be closed
            myservo.write(0);
            digitalWrite(redLed, HIGH);
            digitalWrite(greenLed, LOW);

        }

        void loop() {
            //create a veriable for detecting distance in cm
            unsigned int distance = sonar.ping_cm();
            // printing out distance to serial monitor
            Serial.print("Distance: ");
            Serial.print(distance);
            Serial.println(" cm");

            delay(300);

            // create a variable to measure the capacitive sensor value
            long touchValue =  touchSensor.capacitiveSensor(30);
            // printing the touch value to confirm the threshold
            Serial.print("Touch Value: ");
            Serial.println(touchValue);

            delay(300);
            // check if an object is approaching within 15 cm or if capacitive sensor is touched to open door
            if ((distance < 15 && distance > 0) || touchValue > threshold ){
            digitalWrite(greenLed, HIGH);
            digitalWrite(redLed, LOW);
            myservo.write(90); // open door
            }
            // if not close door if object is beyond 20 cm and the capacitive sensor is not touched
            else if ((distance > 20 || distance == 0) && touchValue <= threshold ){
                digitalWrite(greenLed, LOW);
                digitalWrite(redLed, HIGH);
                myservo.write(0); // close door
            }

        }

1: Motor Pulse Widths at Different Angles

These graphs show how the servo motor uses different pulse widths to control its position: 1 ms at 0°, 1.5 ms at 90°, and 2 ms at 180°. Each pulse repeats every 20 ms.

Motor Voltage Over Time

2: I would take multiple sensor readings and sort them from smallest to largest, then select the median instead of the average. The average would include the erroneous reading in its calculation, which could affect the result. Using the median reduces the impact of occasional incorrect readings because it selects the middle value rather than averaging all the values. This helps the program produce more reliable measurements.

3: For this situation, averaging would work best because we do not have significantly incorrect readings, but rather small fluctuations in the measurements. Therefore, taking multiple readings and calculating their average would help reduce these fluctuations and provide a more accurate and stable measurement.
