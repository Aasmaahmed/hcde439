Final Project Proposal: Mommy's Time

Project Concept and Motivation

Mommy's Time is an interactive visual timer that helps young children understand when their mom needs personal time and how much longer they need to wait. Parents can set the duration and start a countdown. The timer uses colored LEDs, an LCD display, and a buzzer to communicate its progress and signal when time is up.

Anticipated Bill of Materials

  • Arduino Uno R3
  • Breadboard
  • Potentiometer (to adjust timer duration)
  • Push button (to start the timer)
  • 16×2 LCD display (to show the remaining time)
  • 3 LEDs (red, yellow, and green for visual communication)
  • Passive buzzer (to play a sound when the timer ends)
  • 3 × 100 ohm resistors (for the LEDs)
  • Foam/cardboard (for prototype)
  • Potentially stickers (for visuals)
  • Mounted push button (for final prototype)

Contingency Plan

If I have issues with the outputs or run out of Arduino pins, I can focus on two outputs instead of three. My main concern is the LCD display since I haven't used it before. If it doesn't work, I can use the LEDs and buzzer to show the timer's progress while keeping the main functionality.
